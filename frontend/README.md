# hackathon-1-Idea-2-Priyanshu-Kumawat

## A Una Milla - Flight Reward Points & Savings Optimization Platform

A modern web application built for travelers to search flights, optimize frequent flyer loyalty points, and maximize savings with point-redemption hacks.

---

### 🚀 Features

- **Multi-Mode Flight Search**:
  - One-Way, Round-Trip, and Multi-City routes.
  - Airport autocompletion & swap support.
  - Dynamic cabin class & passenger controls.
- **Points Shortfall & Savings Calculator**:
  - Real-time comparison between cash fares and award mileage.
  - Calculated savings in USD and percentages.
  - Custom shortfall points purchase guidance.
- **Popular Award Travel Hacks**:
  - Curated route presets with high value per point redemption.
- **Saved Trips & History**:
  - Save custom flight itineraries with local persistence.
- **Responsive & Modern Design**:
  - High-performance UI built with React 19, Vite, Tailwind CSS, and Lucide icons.

---

### 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Unit Testing**: Vitest
- **Linting**: Oxlint

### 💻 Getting Started

#### 1. Clone the repository
```bash
git clone https://github.com/priyanshu0093/hackathon-1-Idea-2-Priyanshu-Kumawat.git
cd hackathon-1-Idea-2-Priyanshu-Kumawat
```

#### 2. Install dependencies
```bash
npm install
```

#### 3. Run development server
```bash
npm run dev
```

#### 4. Run tests
```bash
npm run test
```

#### 5. Build for production
```bash
npm run build
```
